TEGARIS82 Android project (Android Studio)

Ini adalah project sumber Android yang membungkus prototipe web TEGARIS82 dalam WebView. File APK belum dikompilasi.

Membuat APK:
1. Ekstrak ZIP.
2. Buka folder TEGARIS82_Android di Android Studio.
3. Tunggu Gradle Sync selesai dan pasang Android SDK 35 bila diminta.
4. Pilih Build > Build Bundle(s) / APK(s) > Build APK(s).
5. APK debug biasanya tersedia di app/build/outputs/apk/debug/app-debug.apk.
